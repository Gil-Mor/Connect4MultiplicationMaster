# Connect 4 Multiplication Master

Connect 4 Multiplication Master is an educational web-based game designed to help children master their multiplication tables through engaging, strategic gameplay. By combining the classic "four-in-a-row" mechanics with math challenges, kids stay motivated to practice and learn.

Vibe-coded with my 8 yo using Gemini.

[Play online](https://gil-mor.github.io/Connect4MultiplicationMaster/)
